#🎬 IMDb Sentiment Analysis

##📌 Project Overview

This project uses Machine Learning and Natural Language Processing (NLP) to analyze IMDb movie reviews and classify them as Positive or Negative.

The main goal is to understand the sentiment expressed in movie reviews using text classification techniques.

##🎯 Objectives

- Analyze movie reviews.
- Preprocess textual data.
- Build a sentiment classification model.
- Predict whether a review is positive or negative.

##🛠️ Technologies Used

- Python
- Machine Learning
- Natural Language Processing (NLP)
- Pandas
- NumPy
- Scikit-learn

##⚙️ Installation

1. Clone this repository:

git clone https://github.com/manognaprabhala-svg/IMDb-Sentiment-Analysis.git

2. Navigate to the project folder:

cd IMDb-Sentiment-Analysis

3. Install the required libraries:

pip install pandas numpy scikit-learn

##▶️ How to Run

Run the Python file:

python sentiment_analysis.py

##📊 Dataset

The project uses an IMDb movie review dataset containing movie reviews and their sentiment labels.
